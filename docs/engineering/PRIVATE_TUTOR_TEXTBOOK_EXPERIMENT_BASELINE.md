# 私教真实整册数学教材实验基线

日期：2026-08-28

## 实验对象

- 教材：义务教育教科书《数学 四年级 上册》（2022 年 8 月第 2 版）；
- 本地归档：49,129,912 字节、126 页，SHA-256 `0c54d6710c7d01899e1bdab716021cc66e20e260264a286acc5a119e43557301`；
- OCR：`private-tutor-textbook-page-v2`，每 8 页一个检查点，共 16 个分片；
- 单元真值：根据教材目录人工标注 9 个单元的名称、印刷页码和源文件页码；
- 学科路由对照：整册数学教材、人工整理的数学单元、Loop Engineering 论文、动态热机械分析仪资料，共 4 份真实资料。

实验报告不保存教材正文，只保存指标、页码、置信度、复核原因和学科识别信号。

## 指标口径

| 指标 | 口径 | 门槛 |
| --- | --- | --- |
| OCR 单元标题召回率 | 真实单元标题是否出现在标注的源文件页 | 观察指标 |
| 知识地图单元召回率 | 真实单元是否形成 `textbook_units_v1` 模块 | 不低于 90% |
| 数学误判率 | 数学资料漏判与非数学资料误判之和 / 对照资料数 | 0% |
| 待校对页率 | 触发低置信度或数学结构复核的页数 / 总页数 | 不高于 25% |
| 人工校对成本 | 待校对页数 × 90 秒/页 | 估算值，不冒充真人计时 |

- `low_page_confidence`：1 页，与低文字块置信度重叠。

待校对源文件页码为：3、4、6、7、8、22、33、35、41、44、48、121、122、123、124、125、126。

## 实验发现与修复

首轮真实数据中，OCR 已找齐 9 个单元标题，但知识地图仅支持“第 N 单元”格式，真实教材使用“数字 + 标题”，导致知识地图召回为 0/9。

加入基于页首 heading、连续单元编号和来源章节对齐的识别后，召回提升到 8/9。第二轮发现练习标题“5 解答下面的问题。”抢占第 5 单元编号，因此继续排除以句号、问号或冒号结尾的题目句。最终知识地图单元召回达到 9/9，并保留已有“第 N 单元 / Unit N”兼容路径。

## 可重复运行

已有检查点时离线复算，不发送教材页图：

```powershell
pnpm eval:private-tutor:textbook -- --strict
```

首次识别或明确刷新识别结果时，必须显式允许云端 Codex OCR：

```powershell
pnpm eval:private-tutor:textbook -- --run-ocr --allow-cloud --strict
```

默认机器报告位于 `.myagenttool/evaluations/private-tutor-textbook/`，OCR 页图与分片可恢复复用。

## 真人抽检与计时

启动只绑定本机回环地址的抽检台：

```powershell
pnpm review:private-tutor:textbook
```

然后访问 `http://127.0.0.1:4319`。抽检台直接复用已缓存的 17 张受控原页与 OCR 结果，计时从每页加载完成开始。真人需要逐页：

1. 对照原页检查印刷页码和 OCR 文字；
2. 判断门禁是有效触发、误触发、混合触发还是仍不确定；
3. 对误触发或混合触发选择具体原因；
4. 勾选本人复核声明后提交。

评测记录只保存原文与修正文的 SHA-256、是否修改、估算修改字符数、耗时、触发判断和原因，不保存教材正文。可随时离线查看进度：

```powershell
pnpm review:private-tutor:textbook -- report
```

2026-08-28 的抽检记录已完成 17/17：文字与印刷页码修改均为 0，误触发与混合触发均为 0，17 页全部标记为有效触发。门槛决策因此为 `retain_current_threshold`，不放宽全局低置信度门槛，也没有误触发原因支持定向删减规则。

抽检台记录的总耗时为 52 秒（0.9 分钟），中位数 1 秒/页，P90 为 14 秒/页；其中 13/17 页不超过 2 秒。该分布不足以代表实际逐页对照成本，因此不得用 0.9 分钟替代原先透明标注的 25.5 分钟估算。后续应在真实校对流程或重新计时的代表性样本中补测人工成本。

## 14 天真实学习试验口径

整册知识地图仍须在应用内逐项确认来源与结构，生成并确认教学内容后才能发布；发布包还须通过运行时题目校准并激活，才能建立试验。试验固定包含 14 天学习期和 2 天只结算末尾复测的观察期，不从自动化测试或历史演示数据补算成绩。

- 课程完成率：14 个学习日中至少完成一节课程的独立日期数；
- 次日回忆：课程设定的次日复习时间到期后，48 小时内首次符合条件的独立、无提示作答；
- 延迟复测：错题完成变式阶段后，按计划到期的延迟复测结果；
- 错题收敛：本轮出现的每类错因，只有在最后一次出错之后完整完成纠错链才计为收敛；收敛后再次出错单独计为重开；
- 次日回忆、延迟复测和错题收敛各至少 3 个真实样本才标记为可初步判断，样本不足时保持“暂无”。

## 边界

- 17 页已产生带真人确认声明的抽检记录，但 13/17 页计时不超过 2 秒，不能作为可信人工校对成本；25.5 分钟仍只是一项透明估算；
- 学科误判基线只有 2 个数学正例和 2 个非数学负例，足以验证本切口，不足以代表所有教材；
- 本轮抽检记录没有绕过知识地图发布前的人审门禁；其门槛标签可用于保留当前策略，但异常短的计时不可用于推断真实人力成本；
- 课程发布、真实学习者 14 天连续试学、次日回忆和延迟复测仍需后续真实使用产生证据。
