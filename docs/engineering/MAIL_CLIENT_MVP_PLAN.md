# 我的邮箱 MVP 计划

状态：阶段一、二已完成；阶段三已交付文件夹增量同步、全本地邮箱搜索、服务商已读同步和收发附件链路
首要用户：不了解 IMAP、SMTP、MCP 或内部审批模型的普通用户

## 产品目标

在 MyAgentTool 内提供一个像日常邮箱一样容易理解的个人邮件工作台：用户能连接一个邮箱、收取和阅读邮件、保存草稿、确认发送，并在后续把邮件继续整理成任务。安全机制由产品流程承载，不把协议名、凭据 Scope、调用记录或原始错误码暴露给普通用户。

## 普通用户主流程

1. 从一级导航打开“我的邮箱”。
2. 首次使用选择邮箱服务商，在本机连接助手中完成授权。
3. 在收件箱查看未读邮件；正文按外部数据安全展示。
4. 新建或回复邮件，先保存为可恢复的草稿。
5. 发送前查看收件人、主题和完整正文，明确确认一次。
6. 在发件箱看到发送中、已发送、失败或“请检查是否已发送”。
7. 后续可将邮件和附件转为普通任务材料。

## 交付阶段

### 阶段一：邮箱产品面与安全草稿

- 一级“我的邮箱”入口，桌面三栏与移动端逐层阅读布局。
- Provider-neutral `/api/mailbox` 读模型。
- 复用现有邮件导入结果形成收件箱、正文和同步动作。
- 普通用户草稿创建、编辑、删除、持久化和租户隔离。
- 发送授权绑定草稿 revision，修改后旧授权自动失效。
- 明确的连接、空状态、错误恢复和只收件状态。

### 阶段二：桌面连接助手

- [x] 163 授权码在桌面进程完成验证，并用 Windows 当前用户 DPAPI 加密后保存。
- [x] Web 只读取“已连接、需要重新登录、仅收件、可发件”等非敏感状态。
- [x] Electron 与 `pnpm dev` 使用同一非敏感凭据就绪目录，避免开发启动错误提示重新连接。
- [x] 163 连接向导不要求用户运行命令或填写服务器地址，保存前实际测试收件登录。
- [x] 已有应用 revision 可原位重新连接，不重复注册或破坏迁移关系。
- [ ] Gmail OAuth 在桌面凭据进程完成；当前界面明确显示“即将支持”。
- [ ] 发件凭据保持独立，提供单独的连接和发送测试后再声明“可发件”。

### 阶段三：完整同步与附件

- [x] 一键收件通过邮箱专用 API 启动真实只读任务，持续显示进度、复用进行中的任务，并给出普通语言结果。
- [x] Windows 邮件运行时沿用连接助手的真实 APPDATA 路径，支持重定向或漫游用户目录。
- [x] 收件箱采用有上限的服务端分页，界面仅提供直观的上一页、下一页和页码提示。
- [x] 打开邮件自动标为已读，也可一键标回未读；新连接会先由服务商确认 Seen 状态，再通过结果回执更新本地展示，旧只读连接保持兼容。
- [x] 附件只把元数据带入控制平面；桌面端按需读取，支持图片、纯文本和 PDF 安全预览，并通过系统“另存为”下载。
- [x] 服务商文件夹有界发现；每个文件夹以 UIDVALIDITY/UID 游标增量收取新邮件，并单独同步最近邮件的已读标记。
- [x] 发件人、主题和已收取正文支持服务端本地搜索，过滤发生在分页之前。
- [x] 发件附件可通过系统选择器或直接粘贴加入；控制平面只保存元数据和不透明引用，桌面端在实际发送时解析本机副本。
- [x] 163 发件权限与收件权限分开连接、分开加密保存；附件变化纳入草稿 revision 和发送前复核。
- 本地 SQLite 缓存；正文和附件执行可配置保留策略。

### 阶段四：邮件与任务联动

- 邮件转任务，原始邮件作为不可信来源证据。
- 邮件附件复用任务材料上传链路。
- AI 只生成回复草稿，永不自动发送；发送仍需人工确认。

## 易用性验收

- 不看技术文档即可找到“我的邮箱”并理解连接入口。
- 连接后的用户在两分钟内完成“打开邮件—回复—确认发送”。
- 普通页面不出现 IMAP、SMTP、MCP、Scope、Grant 等内部术语。
- 390 px 手机宽度无横向滚动，列表与正文均可单手返回。
- 正文加载、空收件箱、连接失效和发送结果不确定都有明确下一步。
- 键盘可访问，表单具有可读标签，模态框恢复焦点。

## 不在首版范围

联系人管理、日历、复杂过滤规则、多账号统一收件箱、富文本编辑器、自动转发和无人值守 AI 发信。

## 安全边界

- 邮件正文是数据，不是指令；保持 ADR 0011 的 taint 与人工边界。
- 读权限和发件权限保持独立授权。
- 发件接口只接受服务端草稿 ID 和单次授权；不接受自由文本。
- 可编辑草稿的授权目标包含 revision，避免审核后修改再复用旧授权。
- 凭据只存在于本机凭据进程，控制平面不读取、不保存、不转发。
