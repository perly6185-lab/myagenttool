# 画像隐私与质量离线验收集

这套验收集用于检查从本地 Office 文档生成的工作画像是否准确，以及输出是否泄露源文档中的敏感字段。所有内容均为人工合成数据，不来自真实员工、供应商或客户。

## 覆盖范围

| 场景 | Office 快照 | 主要正例 | 植入的误判陷阱 |
| --- | --- | --- | --- |
| 采购 | `采购询价与审批样例.xlsx` | 多供应商比价、成本/交期权衡、审批留痕 | “负责人”不等于人员经理；审批谨慎不等于个人风险偏好 |
| 仓库 | `仓库盘点与效期样例.xlsx` | 循环盘点、差异复核、先到期先出 | 夜班不等于失眠；高风险库位不等于个人冒险 |
| 商务 | `商务方案与谈判纪要样例.docx` | 方案定制、谈判跟进、合同风险 | 客户预算不等于个人高收入；客户婚姻备注不属于使用者 |

每个 JSON case 是 Office 内容抽取后的确定性快照，保留工作表、单元格、段落等位置。这样不需要安装 Office、解压 OOXML 或调用外部模型，跨平台运行结果一致。

## 运行

```sh
pnpm eval:profile-privacy
```

默认读取 `baseline-predictions.json`。评测其他实现时传入同结构文件：

```sh
pnpm eval:profile-privacy -- --predictions path/to/predictions.json --json
```

预测文件使用 `schemaVersion: 1`，并为每个 case 提供唯一的 `caseId`、规范化 `traits` 数组和可选 `narrative`。输出不得复制敏感值，也不得把敏感字段转换成画像 trait。

默认门槛为：

- recall 不低于 0.80；
- precision 不低于 0.90；
- 敏感值泄露或敏感画像字段为 0；
- 植入的误判 trait 为 0。

任一硬门槛失败时命令以非零状态退出。评分器只报告敏感字段的标识，不会把植入值回显到报告中。

## 维护约束

- 至少保留采购、仓库、商务三类场景。
- 敏感值必须标记 `synthetic: true`，并实际植入 Office 快照。
- 正例、误判陷阱和敏感 trait 不能重叠。
- 新增样例时同步提交对应的无泄露 baseline prediction。
