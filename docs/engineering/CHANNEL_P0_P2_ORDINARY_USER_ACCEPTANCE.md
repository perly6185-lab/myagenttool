# iLink 普通用户 P0-P2 验收

目标：用户只用自然语言完成咨询、任务、补充、确认、排队、授权和结果交付，不需要知道任务 ID、Invocation、Issue、Bridge 或命令语法。

## 必跑场景

1. 发送“你好”：直接回复，不创建任务。
2. 发送“为什么发布失败？”：作为咨询回答，不创建正式任务。
3. 发送“只读取当前目录，列出 3 个文件，不要修改”：由受控本地文件能力直接返回相对文件名，不进入 Agent 队列；若本地读取暂不可用，才降级到受约束的只读 Agent 路径。
4. 连续发送任务说明和两条补充：合并成一个待确认草稿。
5. 在任务执行中发送“只看华东客户”：建立紧随当前任务的后续调整，不取消、不改写当前执行。
6. 重复发送同一任务：复用现有任务；旧的无执行“需要关注”副本自动归档。
7. 发送含糊短句：若 Bridge 可用则辅助分类；否则提出与上下文相关的澄清问题，不误建任务。
8. 发送图片、语音或文件：立即说明已收到的媒体类型，再整理任务理解。
9. 普通授权：微信回复“确认授权”可继续；高风险授权必须提示“打开 MyAgentTool → 审批中心”。
10. 长任务：排队、开始、等待补充、等待授权、完成和失败均主动通知；无新阶段时按策略限频报状态。
11. 结果发送失败：自动重试；最终失败后可回复“重发结果”。
12. 服务重启：恢复排队/执行关联，投递不重复，旧重复任务不重新出现。

## 通过标准

- 普通回复不出现内部任务 ID、Invocation、Issue、Allowlist 或命令说明。
- 明确、低风险且能力已覆盖的只读请求不再要求用户二次确认，也不会被判定为文件修改；结果不出现绝对路径、英文报告模板或内部运行信息。
- 模糊意图预检不与正式任务竞争 Bridge 执行资源，超时后立即降级。
- 运行中补充有清晰归属，且后续任务排在原任务之后。
- 桌面频道页默认只展示连接、工作位置、提醒、任务状态和交互记录；诊断信息按需展开。
- 高风险、文件应用和其他不可逆操作继续遵守桌面审批边界。
- 体验指标可统计针对性澄清、明确只读、本地直达结果、重复任务处理、运行中补充、重试通知去重和媒体回执。
