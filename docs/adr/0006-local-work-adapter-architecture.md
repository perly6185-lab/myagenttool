# ADR 0006: 本地工作适配架构与数据流

- 状态：已接受
- 日期：2026-07-26

## 背景

本地工作适配需要让 Web 界面发起任务，同时允许任务使用用户明确选择的本机内容。系统必须把本机文件系统视为独立的信任域：原始文件及其完整内容默认留在本机，远端服务不能获得浏览或扫描本机文件系统的能力。

## 决策

系统分为 Web、Server 和 Bridge 三个部分。

### 职责与信任边界

| 部件 | 运行位置 | 职责 | 明确禁止 |
| --- | --- | --- | --- |
| Web | 用户浏览器 | 展示任务和结果；收集用户操作；展示上传前的范围、目的与确认状态 | 直接访问本机任意路径；绕过 Bridge 读取文件；把未确认的原始内容发送给 Server |
| Server | 受控服务端 | 身份认证、任务编排、状态同步和远端处理；只接收协议中声明的数据 | 请求目录遍历、通配符或任意路径；安装本机扫描器；通过 Bridge 搜索、索引或枚举用户文件系统 |
| Bridge | 用户本机 | 执行本机能力；校验用户授权；只读取用户逐次明确选择的文件；在本机完成可行的提取、脱敏与缩减 | 后台全盘扫描；扩大用户选择范围；默认上传原始文件或完整内容 |

Bridge 是本机文件访问的唯一入口。Server 只能使用不可反向解析为本机路径的 `selection_id` 引用一次明确选择，且只能请求该选择已授权的操作。Bridge 不接受来自 Server 的绝对路径、相对路径、目录、glob、搜索词或递归标志。

### 数据流

1. Web 创建任务，但不包含本机文件内容。
2. 用户在本机选择器中明确选择文件，并看到用途、接收方和将要离开本机的数据摘要。
3. Bridge 创建短期 `selection_id`，记录选择范围与授权操作；本机路径不会发送给 Server。
4. Bridge 优先在本机处理。仅当任务确有需要且用户针对本次传输确认后，Bridge 才发送最小必要的派生内容或明确选择的原始内容。
5. Server 处理获准的数据并返回任务状态或结果；Web 负责展示。
6. 授权到期、任务取消或完成后，Bridge 使 `selection_id` 失效并按下表清理临时数据。

默认数据流为：

```text
本机文件 -> Bridge（选择、处理、脱敏） -> 派生数据/明确确认的原文 -> Server
                                             |
Web <----------- 状态与结果 -----------------+
```

“原始内容不离开本机”是默认值。例外必须同时满足：用户主动选择具体文件、界面说明传输目的和接收方、用户对本次传输明确确认、传输范围可审计。一次确认不得复用于其他文件、任务或接收方。

### 数据存储与保留期

| 数据类别 | 默认存储位置 | 默认保留期 | 说明 |
| --- | --- | --- | --- |
| 原始文件及完整原始内容 | 用户原有本机位置；Bridge 不持久复制 | 原文件由用户管理；Bridge 内存副本在操作结束时释放 | 默认不得发送至 Server 或 Web 存储 |
| 本机路径、文件名和选择清单 | Bridge 本机受限存储 | 任务完成、取消或 24 小时，以先到者为准 | Server 仅见随机 `selection_id`；日志不得记录路径 |
| Bridge 临时文件和提取缓存 | Bridge 的应用专用临时目录 | 操作结束立即删除；异常残留最迟 24 小时清理 | 不得置于 Web 可访问目录 |
| 派生内容（摘要、脱敏文本、结构化片段） | 优先在 Bridge；经确认后可进入 Server 任务存储 | Bridge：任务结束；Server：任务结束后 30 天 | 用户或管理员可提前删除 |
| 经用户明确确认上传的原始内容 | Server 的隔离任务对象存储 | 任务结束后 7 天 | 加密、按任务隔离；不得用于训练或其他任务 |
| 任务元数据（任务 ID、状态、时间、内容类型、大小） | Server 数据库 | 90 天 | 不包含本机路径、文件正文或可恢复正文的摘要 |
| 审计记录（确认主体、范围、目的、结果） | Server 审计存储；Bridge 保留本机传输记录 | 180 天 | 只记录标识和哈希等最小证据，不记录原始内容 |
| Web 会话状态和展示结果 | 浏览器内存；必要时使用会话存储 | 标签页/会话结束时清除 | 禁止把原始内容写入持久化浏览器存储或分析事件 |
| 服务运行日志与指标 | 对应部件的受限日志系统 | 30 天 | 必须过滤正文、本机路径、凭据及选择清单 |

部署可以缩短保留期，但不得在没有新的架构决策、安全审查和用户告知的情况下延长保留期。删除包含主存储、缓存、索引、日志附件和备份中的可寻址副本；备份副本应在 30 天轮换窗口内过期。

### 强制文件访问约束

- Server API 不得提供或接受 `path`、`directory`、`glob`、`recursive`、`searchRoot` 等本机发现参数。
- Bridge 只处理由操作系统文件选择器或等价的、用户可见的逐次授权产生的句柄。
- 目录选择默认禁止；若未来需要，必须另立 ADR，定义可见范围、文件上限、预览和逐次确认。
- Bridge 必须拒绝超出选择句柄范围的请求，包括符号链接或连接点导致的范围逃逸。
- 服务端下发任务不能触发文件枚举。协议未知字段应被拒绝，而不是作为路径或扫描选项透传。
- 测试和评审应把“Server 无法任意扫描本机文件系统”作为安全不变量。

## 后果

本地能力由 Bridge 承担，Server 可以在不了解本机路径的情况下编排任务。该设计减少原始内容外泄和静默扫描风险，但需要本机选择交互、短期授权管理、内容最小化以及跨端删除机制。需要批量目录处理或长期索引时，不能扩展现有接口绕过约束，必须单独评审并取得新的明确授权。
