## 核心主题 (一句话)

Voxa 是一套开源工具，让开发者通过手机语音远程向 AI 编程代理下达任务，代理在电脑上自动执行，完成后自动回拨电话通知结果——实现"用嘴说、用耳朵听"的离座编程体验。

---

## 关键观点 (5 条)

### 1. 语音→执行→回铃的闭环体验

用户对着手机说出编程任务（如修 bug），Voxa 将语音转文字后发给电脑端 AI Agent，Agent 自动完成任务后拨打用户手机进行语音回铃通知。

> **原文支撑**: 「核心体验：用户语音输入 → AI 代理在电脑上执行任务 → 任务完成时自动拨打用户手机回铃通知。」

### 2. 当前平台与 Agent 支持范围有限

已有实测验证的组合是 macOS + iPhone + Claude Code；Windows 可用但未测试，Android 暂不支持，Codex 和 Gemini 尚未接入。

> **原文支撑**: 「支持平台：macOS 和 iPhone 已实测通过；Windows 可用但尚未测试；Android 暂未支持。」「支持的 AI 代理：Claude Code 已确认可用；Codex 和 Gemini 尚未支持。」

### 3. 自托管完全免费，托管服务免费起步

自托管方案无需依赖官方中继，只需自带 API Key 即可运行。官方也提供零配置托管式中继/推送服务，免费起步，付费计划解锁更多代理分钟数。

> **原文支撑**: 「自托管方案完全免费，只需自带 API Key，无需依赖官方中继服务（完整文档见 voxa.space/docs）」；「官方也提供托管式中继/推送服务，零配置安装，免费起步，付费计划可解锁更多代理分钟数。」

### 4. 双层开闭源架构

仓库中的笔记本端服务器和手机端 Web 客户端均以 MIT 协议开源；原生 iOS App 与托管中继/计费服务位于独立私有仓库，构成"开源基础 + 商业增值"模式。

> **原文支撑**: 「架构分两层：仓库包含笔记本端服务器和手机端 Web 客户端（均 MIT 开源）；原生 iOS App 和托管中继/计费服务位于独立私有仓库中。」

### 5. 面向"离座编程"场景设计

典型使用场景是程序员不在电脑前（散步、通勤等），突发灵感或想到 bug，通过 Voxa 远程指挥 AI Agent 干活，全程无需碰键盘。

> **原文支撑**: 「你完全不需要坐在电脑前，全程只用嘴说、用耳朵听。」以及开篇散步修 bug 的完整示例场景。

## 作者的结论

Voxa 将 AI 编程代理的交互从"必须坐在电脑前打字"解放为"随时随地用语音指挥"，就像给 AI Agent 装了一个电话助手。它目前处于早期但核心闭环已跑通（macOS + iPhone + Claude Code），自托管免费方案降低了上手门槛，托管服务则面向零配置用户。整体定位清晰——不是另一个 AI 编程工具，而是 AI 编程代理的"语音远程控制层"。
