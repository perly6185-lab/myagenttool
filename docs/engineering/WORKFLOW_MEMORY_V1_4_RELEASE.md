# Workflow Memory V1.4 商务日常工作指南与发布审核

Workflow Memory V1.4 可以从用户明确选择的本地工作目录中，协助归类询价、报价、订单、价格资料和业务台账；在用户确认历史案例后，把重复工作发布为本地 Issue 任务类型。它不会自行理解整台电脑，也不会在后台静默学习。

## 普通用户：从历史目录到“一键处理询价”

1. 打开“交付记忆”，选择包含历史询价、报价和台账的工作目录，并授权只读扫描。
2. 检查系统提出的文件归类和案例关系。错误项必须由用户确认或修正，未知文件可以继续保持未知。
3. 当至少有 3 个可信历史案例时，检查识别出的日常工作步骤；确认触发条件、每次必做步骤、条件步骤、输出、台账和人工审批点。
4. 勾选明确确认后启用该工作类型。已启用版本不会被后续编辑静默改变。
5. 新询价进入授权目录后，打开系统生成的本地 Issue，点击“处理询价”。
6. 按编号步骤检查询价登记、参考资料、报价文件和报价登记。每次台账写入都会先显示新增或更新的行及单元格，再由用户确认。
7. 报价必须人工检查后才能继续。收到真实且已确认的订单文件时，选择该文件并创建订单交接；没有订单时选择“尚未收到订单”，订单分支会明确跳过。

重复点击、重复导入和服务重启会复用同一业务编号及证据对应的任务或结果，不应重复生成 Issue、输出或台账行。若文件在预览后被其他程序修改，系统会停止写入并要求刷新。

## 支持范围与数据边界

- 可从 Markdown、纯文本、HTML、CSV、DOCX、XLSX 和含文本层的 PDF 提取有界文本。扫描 PDF、图片 OCR、复杂版式恢复和宏工作簿不在 V1.4 保证范围内。
- CSV 台账支持受控分隔符、BOM 和换行保留；XLSX 支持指定工作表区域或命名 Table，并保留无关工作表、样式和公式。不能安全保留的公式行插入会被阻止。
- 默认分类、字段提取、案例关系和评测全部在本机完成。可选语义 Provider 必须是用户显式配置的 loopback HTTP 服务；发送前限制长度并脱敏，不跟随重定向。
- 系统只读取用户授权来源内的文件，不扫描整盘，不向界面或 Provider 暴露额外绝对路径，也不会把原文、Prompt 或秘密字段复制进学习记录。
- 文件名只能形成低置信度建议。业务编号、正文证据和用户确认优先；证据冲突、提示词注入、疑似秘密和电子表格公式值会进入风险状态，不会被强行猜测。

## 修正、版本、恢复与审计

- 分类、案例和任务类型的修正都使用修订号，过期页面不能覆盖较新的用户决定。
- 发布版本不可编辑；修改会创建新草稿版本。新版本发布后，旧任务仍固定旧版本，停用只阻止新任务。
- 扫描或步骤进程中断后会显示“可恢复”或“步骤中断”，保留已完成步骤；用户从明确失败点重试。
- 台账预览 15 分钟失效，并绑定目标文件版本、业务键、目标行和字段。并发修改、活动锁、符号链接、目录越界或过期审批都会阻止写入。
- 审计记录操作者、审批人、来源证据 ID、Routine 版本、前后文件哈希、变更字段和恢复结果；不保存无关台账行。
- 撤销来源授权会停止新分析和新任务。删除派生学习数据会清理该来源的分类、案例、画像、Routine、索引和运行派生记录，但不会删除用户原始文件。

## V1.4 发布评测

确定性发布夹具位于
`apps/server/test/fixtures/workflow-memory/commercial-routine-v1.4.json`，包含：

- 3 组询价—报价历史、询价与报价台账；
- 1 个真实订单及订单台账、2 个无订单结果；
- 1 个重复询价、1 个无法配对报价、未知文件和提示词注入样本；
- 路径逃逸、符号链接、秘密值、恶意公式、过期审批、跨租户和 Provider 边界场景；
- 扫描/步骤重启、并发台账编辑和原子替换后恢复场景。

运行：

```bash
pnpm test:commercial-routine-release
pnpm eval:commercial-routine
pnpm exec playwright test -c apps/web/playwright.config.ts workflow-memory-routine.spec.ts
```

| 维度 | 证据与结论 |
| --- | --- |
| 功能 | 授权目录 → 归类/修正 → 案例 → Routine 审核/发布 → 本地 Issue → 台账预览/提交 → 报价审批 → 条件订单路径均有自动化覆盖。 |
| 性能 | 文档分析和步骤执行使用服务级有界并发；评测夹具本机执行不调用付费或网络 Provider。 |
| 安全 | 目录边界、链接逃逸、公式注入、提示词注入、秘密脱敏、过期审批、幂等和跨租户拒绝纳入专用发布测试。 |

| 回滚 | 停用 Routine 阻止新任务但保留历史；撤销来源停止新派生；代码回滚不删除原文件或已写审计。台账写入使用同目录暂存、同步和原子替换。 |
