# P4.16 P1 真实业务场景验收

## 执行

```bash
pnpm test:p1:real-scenarios
```

报告写入 `.myagenttool/real-scenarios/p1-report.json`。

## 场景范围

| 场景 | 验收重点 |
| --- | --- |
| 开发类长任务 | 同一 worktree、进度、结果、反馈重跑、审批和结果证据 |
| Claude 受治理审查 | 能力调用、固定权限模式、审查发现、Evidence Center 关联 |
| 自媒体/文档素材处理 | 本地文档发现、预览、创建和不上传源文件 |
| 素材结果回传 | 本地素材结果与出站图片/文件媒体保持项目边界并回传到 Channel |
| 同一任务修改闭环 | 结果复核、提出修改、继续执行、历史版本和审计连续性 |

## 通过标准

- 用户不需要知道 invocation ID、run ID 或 worktree ID。
- 长任务期间能看到处理中状态，失败时能重试或继续处理。
- 结果不满足要求时，修改要求仍绑定原任务和原始输入。
- Agent 的执行目录、权限、结果来源和审查证据可追溯。
- 未经用户确认的代码或外部动作不会被提升为最终结果。
- 素材处理默认使用本地文件边界，不隐式上传文件。

P1 只验收真实交互闭环，不把 fake bridge 的确定性结果当作真实模型质量结论；实际 Codex/Claude 质量和耗时仍需在用户授权的本机桥接环境中单独观察。
