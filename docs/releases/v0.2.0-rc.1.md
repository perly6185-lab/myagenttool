# v0.2.0-rc.1

This candidate closes M2 with auditable automatic execution and a traceable
Channel task loop.

## Candidate Scope

- request context on Invocations, including model, tools, MCP, and Skills;
- declared CI smoke policy and gated Codex exec contract;
- bounded dispatch/failover/claim recovery in one runtime health view;
- Channel task tracking from Issue through Invocation, result, and delivery;
- retry, same-device reroute, and human takeover for failed Channel tasks;
- shared Provider security/idempotency contracts and complete WeCom acceptance;
- repeatable browser, recovery, capacity, and cross-platform contract gates.

Marketplace publication, full billing, additional Provider features, and broad UI
restructuring remain outside this candidate.

Run the release evidence bundle with `pnpm release:candidate`. Production publish
or deployment still requires explicit human approval.
